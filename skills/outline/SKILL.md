# Outline Usage Guide

Outline is a powerful collaborative knowledge base and documentation platform. This skill helps you integrate Outline into your daily workflow for project management.

## When to Use This Skill

Use this skill when you need to:
- Create and organize project documentation
- Share knowledge with team members
- Build knowledge bases or wikis
- Manage project-related information
- Collaborate on technical documentation
- Track decisions and meeting notes

**Key concept:** Outline is not just for storage - it's for living, breathing documentation that evolves with your team.

## Getting Started with Outline

### Quick Access

1. Open Outline in your browser: `http://your-outline-domain.com`
2. Login or create your first account
3. Start creating documents!

### Basic Concepts

**Collections** act as folders or project containers
- Create collections for different projects, teams, or departments
- Use nested collections to organize hierarchies

**Documents** are the primary content
- Support Markdown formatting
- Real-time collaborative editing
- Can include images, code blocks, tables

## Project Management with Outline

### Project Templates

Use collections and templates for consistent project setup:

**Structure Example:**
```
📁 neovie-dev/
├── 📋 README
├── 📋 Project Planning
├── 📋 Development
├── 📋 Architecture
└── 📋 Deployment
```

**Template Document:**
```markdown
# Project: [Project Name]

## Overview
[Brief description]

## Status
- [ ] Planning
- [ ] In Progress
- [ ] Review
- [ ] Complete

## Decisions
- [ ] [Date] Decision description

## Resources
- Links, tools, documentation

## Next Steps
1. [ ] Task 1
2. [ ] Task 2
```

### Task Tracking

Use Outline for task management:

1. **Create task documents:** Each major task gets its own document
2. **Use headers for status:**
   ```markdown
   ## 📋 Status: In Progress
   ```
3. **Link related tasks:** Use Outline's linking feature
4. **Tag for visibility:** `#urgent`, `#in-progress`, `#done`

### Meeting Notes

Meeting notes work great in Outline:

```markdown
# Meeting: [Date] - [Topic]

## Attendees
- @name1
- @name2

## Agenda
1. Item 1
2. Item 2

## Notes
[Detailed notes]

## Action Items
- [ ] Owner - Task 1
- [ ] Owner - Task 2

## Decisions Made
- Decision 1
```

## Collaboration Features

### Real-time Editing

- Multiple team members can edit simultaneously
- See cursors showing where others are typing
- Comments and mentions using `@username`

### Sharing & Permissions

**Share externally:**
- Create public links for documentation
- Set expiration dates on shared links
- Password-protect sensitive content

**Team permissions:**
- Read-only access for stakeholders
- Edit access for contributors
- Admin access for maintainers

### Version History

Outline tracks all changes:
- View previous versions of documents
- Compare changes between versions
- Restore earlier versions if needed

## Tips for Effective Use

### Organization

1. **Use nested collections** - Don't flatten everything
2. **Consistent naming** - Use clear, descriptive names
3. **Use icons** - Add emojis to document titles for visual scanning
4. **Regular cleanup** - Archive old projects

### Collaboration

1. **Mention teammates** - Use `@` to notify specific people
2. **Use comments** - Discuss without cluttering the document
3. **Share collections** - Share entire project spaces with teams

### Productivity

1. **Templates** - Create reusable document templates
2. **Keyboard shortcuts** - Learn Outline's shortcuts (try `/` for commands)
3. **Embed content** - Link to external tools from documents

## Integration with Other Tools

### Project Management Integration

Use Outline alongside other tools:

- **Jira/GitHub Issues:** Link to relevant tickets in Outline documents
- **Slack/Teams:** Share Outline links in team channels
- **Email:** Email stakeholders with Outline document links

### Code References

**Embed code in Outline:**
`````
[language]
// Your code here
`````

**Link to repositories:**
- Add links to GitHub/GitLab repositories
- Reference branches or commits

## Search Tips

### Effective Searching

1. **Use specific terms** - Narrow down results
2. **Filter by collection** - Search within specific projects
3. **Use quotes for phrases** - Search for exact phrases like `"user authentication"`

### Bookmarking

Important documents can be bookmarked:
- Add to favorites for quick access
- Use favorites to build a personal dashboard

## Best Practices

### Documentation

1. **Keep it current** - Update as information changes
2. **Use clear headings** - Make documents scannable
3. **Include context** - Add background information
4. **Use examples** - Show rather than tell

### Collaboration

1. **Share early and often** - Don't wait for perfection
2. **Ask for feedback** - Use comments to gather input
3. **Be specific with requests** - Clear questions get clear answers

### Security

1. **Review permissions regularly** - Ensure appropriate access levels
2. **Use private collections** - For sensitive information
3. **Audit shared links** - Check what's publicly accessible
4. **Archive sensitive projects** - Move old projects to restricted access

## Quick Reference

| Task | How in Outline |
|-------|----------------|
| Create new document | Click "New Document" or press `Ctrl+N` |
| Create collection | Click "New Collection" in sidebar |
| Share document | Click "Share" → Generate link or invite |
| Search | Press `/` and type your query |
| View history | Click clock icon in top right |
| Add comment | Highlight text → right-click → Add comment |
