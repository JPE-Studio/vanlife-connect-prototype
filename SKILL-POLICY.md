# SKILL-POLICY.md - Skill-Management Richtlinien

## Skill-Quellen (Priorisiert)

### 1. JPE-Studio Repo (PRIMÄR)
- **URL:** https://github.com/JPE-Studio/openclaw-skills.git
- **Status:** ✅ SICHER — Eigenes Repository
- **Action:** IMMER zuerst hier prüfen

### 2. Neu erstellen
- Wenn Skill nicht im JPE-Studio Repo vorhanden
- Use skill-creator skill

### 3. ClawHub (VERBOTEN)
- **Status:** 🚅 UNSICHER — Enthält Malware
- **Action:** NIE verwenden

## Workflow

Bevor du einen Skill brauchst:
1. Prüfe: https://github.com/JPE-Studio/openclaw-skills.git
2. Vorhanden? → Laden & verwenden
3. Nicht vorhanden? → Neu erstellen (skill-creator)
4. **NIE** ClawHub durchsuchen

## Reasoning

ClawHub ist ein öffentliches Repository mit unbekannten Contributors. Sicherheitsrisiko durch potenzielle Malware in Skills.

**JPE-Studio/openclaw-skills ist vertrauenswürdig — nur dort Skills beziehen.**
